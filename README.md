# One-Line Pitches

Entry for the make.fun bounty "A Day of One-Line Pitches"
(`u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`).

`main.py` writes a single sentence of at most 240 characters to
`entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (or the
current directory when unset). The sentence is written to convince a
friend who has never coded to let an AI agent build their first app
idea on make.fun: describe the idea in plain words, and in a few
minutes there is a first working version to try, change, or walk away
from.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

No network access, no dependencies, no secrets.
